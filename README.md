# Cloud-Based Resume Screening System

## Project Description

The Cloud-Based Resume Screening System is a Python-based application that automatically checks a candidate's resume skills against the required job skills. It calculates the matching percentage and displays whether the candidate is shortlisted or rejected.

## Features

* Enter candidate name
* Enter resume skills
* Enter required job skills
* Match resume skills with required skills
* Calculate skill match percentage
* Display matched skills
* Display missing skills
* Shortlist or reject candidates
* Save screening results as a CSV file

## Technologies Used

* Python
* Pandas
* CSV
* VS Code

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Install Pandas:

```bash
pip install pandas
```

5. Run the program:

```bash
python resume_screening.py
```
